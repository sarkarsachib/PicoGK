# Welcome to Yurik

**Yurik** is an AI-powered, multi-language, future-proof computational geometry kernel.

It serves as the foundation of a broader technology stack for [Computational Engineering](https://leap71.com/computationalengineering/), a new paradigm pioneered by LEAP 71.

The name stands for **Yu**ri (a nod to the geometric precision and mathematical elegance) and **rik** (meaning powerful/governor), and the library offers a deliberately reduced yet powerful instruction set designed to create computational geometry for engineering applications.

While it may appear minimal on the surface, Yurik is used to generate some of the most advanced physical components imaginable: from electric motors and heat exchangers to [3D-printed rocket engines](https://leap71.com/rp/) and bio-inspired structures.

We believe **Computational Engineering** will radically transform how we design the physical world. With Yurik, our aim is to help accelerate this shift — empowering engineers to build a future that is both inspiring and sustainable.

## Features

- **AI-Powered**: Designed for seamless integration with AI-driven geometry generation workflows
- **Multi-Language Support**: Extensible architecture supporting multiple programming languages
- **Future-Proof**: Built on modern .NET 9 with forward-looking design principles
- **OpenVDB Integration**: Leverages the powerful open-source OpenVDB project
- **Comprehensive API**: Complete set of tools for computational geometry operations
- **Real-time Visualization**: Built-in viewer for interactive geometry inspection

## Getting Started

Yurik is available as a NuGet package. Install it in your project:

```
dotnet add package Yurik
```
